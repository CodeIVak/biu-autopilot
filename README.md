# בר-אילן אוטו-פיילוט

ניווט אוטומטי לכיתה הבאה. האפליקציה מושכת את מערכת השעות מ-Inbar, מצליבה אותה עם לוח השנה האקדמי, ופותחת Waze או Google Maps מהמיקום הנוכחי שלך אל הבניין של השיעור.

- אפליקציה שמותקנת על הטלפון ועובדת גם בלי אינטרנט (PWA). אין שרת, ושום נתון לא יוצא מהמכשיר.
- קובץ יומן לכל השנה, בלי חגים וחופשות, עם תזכורת וקישור ניווט.
- קואורדינטות של 37 בניינים בקמפוס, מ-OpenStreetMap ומאומתות מול Google Maps.

**המדריך המלא, לסטודנטים ולמפתחים: [docs/GUIDE.md](docs/GUIDE.md)**

```bash
npm install && npm run dev
```

## משוב והצעות לשיפור

נשמח לקבל משוב, דיווח על תקלות והצעות לפיצ'רים. אפשר לשלוח דרך כפתור **"שליחת משוב"** באפליקציה, או ישירות במייל.
