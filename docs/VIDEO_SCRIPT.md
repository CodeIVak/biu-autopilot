# תסריט Reel: "איפה הכיתה?"

**פורמט:** 9:16 (1080×1920), 30fps, כ-24 שניות, בלי קריינות. הטקסט על המסך והסאונד נושאים את הסיפור.
**סגנון:** Motion graphics על Liquid Glass. המצלמה זזה כל הזמן בקפיצים (springs), ואין חיתוכים קשים.
**קובץ:** `marketing/video/reel.html`. רינדור: `npm run video`.

## מה למדנו מקבוצת הוואטסאפ של התואר (מקור התובנות)

ניתחנו 5,105 הודעות מהקבוצה, מאוקטובר 2024 עד אוקטובר 2026, בלי לשמור שמות או מספרי טלפון. השאלות על מיקום חוזרות בצורות שונות:

| נושא | דוגמאות אמיתיות (בלי שם השולח) |
|---|---|
| איפה הכיתה | "איפה הכיתה", "באיזה בניין חבורות היום?", "באיזה כיתה אנחנו לומדים?" |
| בניינים לא מוכרים | "איפה זה בניין 105?", "בניין 403 חדר 69... אנחנו אשכרה נבחנים כאן?" |
| סטודנטים מנווטים זה את זה | "306 זה הבניין של הקופי מול שער 2, תעלו קומה וזה הכיתה הראשונה" |
| מבחנים | "מישהו יודע מתי ואיפה הבוחן?", "איפה הבחינה? האפליקציה לא נפתחת לי" |

הבניינים שהוזכרו הכי הרבה: 216, 403 ו-306.

**התובנה:** סטודנטים משתמשים בקבוצה כמפה. אנחנו מראים את השאלה במילים שלהם, ואז את הרגע שבו היא נעלמת.
