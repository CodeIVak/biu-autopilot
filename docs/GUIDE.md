# מדריך: אוטו-פיילוט לבר-אילן

האפליקציה קוראת את מערכת השעות שלך מ-Inbar, מצליבה אותה עם לוח השנה האקדמי (סמסטרים, חגים, חופשות), ונותנת לך:

- **השיעור הבא** עם כפתור ניווט אחד ל-Waze או ל-Google Maps.
- **קובץ יומן (.ics)** לכל השנה: אירוע שבועי לכל שיעור, בלי ימי חג, עם תזכורת חצי שעה לפני וקישור ניווט.
- **ניווט אוטומטי** מהטלפון, דרך Shortcuts באייפון או התזכורת של היומן באנדרואיד.

הכל רץ במכשיר שלך. אין שרת ואין חשבון, והסיסמה ל-Inbar לא נשמרת בשום מקום.

## חלק א׳: לסטודנט

### 1. פותחים את האפליקציה ומוסיפים למסך הבית

| | אייפון (Safari) | אנדרואיד (Chrome) |
|---|---|---|
| הוספה למסך הבית | כפתור השיתוף ← "הוסף למסך הבית" | תפריט ⋮ ← "התקנת אפליקציה" / "הוספה למסך הבית" |

אחרי ההתקנה האפליקציה עובדת גם בלי אינטרנט.

### 2. יוצרים את הסימנייה (פעם אחת)

הסימנייה מעבירה את מערכת השעות מ-Inbar לאפליקציה. האפליקציה מזהה את סוג המכשיר ומציגה רק את השלבים שמתאימים לו: אייפון, אנדרואיד או מחשב.

1. באפליקציה לוחצים **"העתקת קוד הסימנייה"**. הקוד קצר, כ-150 תווים.
2. שומרים סימנייה לעמוד כלשהו:
   - **אייפון:** כפתור השיתוף ← "הוספת סימנייה".
   - **אנדרואיד:** תפריט ⋮ ← ☆ ← "עריכה".
3. **עורכים את הסימנייה:** בשם כותבים `אוטו-פיילוט`, ובשדה **הכתובת** מוחקים הכל ומדביקים את הקוד.

**במחשב** גוררים את הכפתור "אוטו-פיילוט" מהאפליקציה לסרגל הסימניות.

> **שימו לב:** לא להדביק את הקוד בשורת הכתובת. הדפדפן מוחק את `javascript:` מהתחלת הטקסט ומחפש אותו בגוגל.

הסימנייה רק טוענת את הקוד העדכני מהאפליקציה. אם Inbar ישתנה והקוד יתוקן, התיקון יגיע לכולם בלי לשמור סימנייה מחדש.

### 3. מושכים את מערכת השעות (פעם בסמסטר, או כשמשהו משתנה)

1. נכנסים ל-[Inbar](https://inbar.biu.ac.il/live/Login.aspx) ומתחברים.
2. מפעילים את הסימנייה:
   - **אייפון:** סמל הספר ← "אוטו-פיילוט".
   - **אנדרואיד:** מקלידים `אוטו-פיילוט` בשורת הכתובת ובוחרים את הסימנייה מהרשימה.
3. מופיעה הודעה "טוען מערכת שעות…", ותוך כמה שניות חוזרים לאפליקציה עם כל השיעורים.

### 4. מוסיפים ליומן

באפליקציה בוחרים כמה זמן לפני כל שיעור תגיע התזכורת ובאיזו אפליקציה לנווט, ואז לוחצים **"הורדת קובץ יומן"**.

- **אייפון:** הקובץ נפתח ישירות ← "הוסף הכל". מומלץ לשמור ללוח שנה חדש בשם "בר-אילן".
- **אנדרואיד / Google Calendar:** האפליקציה של Google Calendar לא מייבאת קבצי `.ics`. פותחים את [calendar.google.com](https://calendar.google.com) בדפדפן ← ⚙️ הגדרות ← "ייבוא וייצוא" ← בוחרים את הקובץ. מומלץ לייבא ללוח שנה חדש בשם "בר-אילן", כדי שקל למחוק אותו בסמסטר הבא.

> כשמעדכנים את המערכת, מוחקים את לוח השנה "בר-אילן" ומייבאים מחדש. כך לא יהיו כפילויות.

### 5. ניווט אוטומטי לכיתה

**הדרך הפשוטה (בלי שום הגדרה):** חצי שעה לפני השיעור מגיעה התזכורת מהיומן. לוחצים עליה, פותחים את האירוע, ולוחצים על קישור הניווט.

**אייפון, ניווט בלחיצה אחת עם Shortcuts:**

1. אפליקציית **קיצורים** ← ➕ קיצור חדש בשם `לשיעור הבא`:
   1. **מצא אירועי לוח שנה** ← סינון: *לוח שנה* הוא `בר-אילן`, *תאריך התחלה* הוא *ב-1 השעות הבאות*. מיון לפי תאריך התחלה, הגבלה ל-1.
   2. **קבל פרטים של אירועי לוח שנה** ← *URL*.
   3. **פתח כתובות URL**.
2. אפשר להוסיף את הקיצור למסך הבית או לכפתור הפעולה (Action Button).
3. **כדי שזה יקרה לבד:** לשונית *אוטומציה* ← ➕ ← *שעה ביום*. מגדירים שעה של חצי שעה לפני כל שעת התחלה שיש לך (למשל 07:30 ו-09:30), בימים הרלוונטיים, ובוחרים *הפעל מיד* ← הקיצור `לשיעור הבא`. אם אין שיעור בשעה הקרובה, למשל בחג, הקיצור לא עושה כלום.

**אנדרואיד, Tasker (למתקדמים):** בונים פרופיל שבודק את לוח השנה "בר-אילן" ופותח את כתובת ה-URL של האירוע הקרוב. אותו רעיון כמו ב-Shortcuts. לרוב התזכורת של Google Calendar מספיקה.

### 6. משוב והצעות לשיפור

בתחתית האפליקציה יש כפתור **"שליחת משוב"** לדיווח על תקלות ולהצעות לשיפור. לשאלות ובירורים: **עידן ועקנין**, [idan.vaknin1@live.biu.ac.il](mailto:idan.vaknin1@live.biu.ac.il).

## חלק ב׳: למפתח

### פקודות

```bash
npm install
npm run dev               # בונה את הסימנייה ומריץ שרת פיתוח
npm test                  # כל הבדיקות (Vitest + happy-dom)
npx vitest run tests/calendar.test.ts   # קובץ בדיקה אחד
npx vitest run -t "excludes holidays"   # בדיקה אחת לפי שם
npm run typecheck
npm run build             # dist/ = אתר סטטי מוכן (PWA)
npm run update:calendar   # מוריד מחדש את לוח השנה האקדמי מ-biu.ac.il
npm run update:buildings  # מעדכן קואורדינטות בניינים מ-OpenStreetMap
```

### פריסה

`dist/` הוא אתר סטטי (`base: "./"`), כך שאפשר לארח אותו בכל אירוח סטטי, למשל GitHub Pages. השרת מגיש רק את קבצי האפליקציה. מערכת השעות עוברת ב-`#fragment` של הכתובת, ודפדפנים לא שולחים את החלק הזה לשרת.

הסימנייה נבנית מתוך האפליקציה עצמה, עם הכתובת שממנה האפליקציה רצה. לכן אחרי פריסה לכתובת חדשה צריך להעתיק את הסימנייה מחדש.

### מבנה

```
src/core/          לוגיקה טהורה, בלי React (נבדקת ב-tests/)
  inbar/           parseSchedule (טבלת GridView → Lesson[]), fetchSchedule (postback "כל הסמסטרים")
  academic/        parseIcs + academicYear (סמסטרים, ימים בלי לימודים); data/<year>.ics
  schedule/        lessonDates / nextOccurrence / currentSemester
  calendar/        buildIcs (RRULE + EXDATE + VALARM + VTIMEZONE)
  navigation/      buildings.json + קישורי Waze/Google Maps
  transfer/        קידוד base64url של הנתונים ל-#import=
src/bookmarklet/   נבנה ל-IIFE יחיד (vite.bookmarklet.config.ts), והאפליקציה מייבאת אותו כ-?raw
src/app/           ממשק React + shadcn/ui (components/ui נוצרו ב-shadcn CLI)
```

### קואורדינטות של בניינים

`src/core/navigation/buildings.json` נוצר מ-OpenStreetMap עם `npm run update:buildings`. כרגע יש בו 37 בניינים בקמפוס (31 מ-OSM, ו-6 שאומתו ידנית מול Google Maps ומסומנים "manual"). נבחרים רק בניינים ששמם מתחיל במספר בניין, או שמסומנים `building=university`. הקואורדינטה היא מרכז קווי המתאר של הבניין. הקישורים פותחים ניווט מהמיקום הנוכחי של הטלפון (`navigate=yes` ב-Waze, `dir` ב-Google Maps).

בניין שחסר, למשל **505** שלא מסומן ב-OSM, מוסיפים ידנית עם `"source": "manual"`. רשומות ידניות לא נדרסות בעדכון הבא:

```json
"505": { "lat": 32.0705, "lng": 34.8445, "name": "505", "source": "manual" }
```

לבניין בלי קואורדינטות, הניווט מחפש לפי טקסט: "אוניברסיטת בר-אילן בניין 505". את המיקום המדויק אפשר לקחת מאפליקציית הקמפוס של בר-אילן. מומלץ גם להוסיף אותו ל-OpenStreetMap, ואז כולם ירוויחו.

### הסימנייה: איך היא עובדת

- `src/bookmarklet/main.ts` נבנה ל-`dist/bookmarklet.js` ומתפרסם ליד האפליקציה, בכתובת `<app>/bookmarklet.js`.
- הסימנייה שהמשתמש שומר היא טוען קצר (`src/bookmarklet/loader.ts`). הוא מוסיף לעמוד של Inbar תגית `<script>` שמצביעה לקובץ הזה. Inbar לא שולח Content-Security-Policy, ולכן הדפדפן מאפשר את זה.
- הקוד מזהה את כתובת האפליקציה מתוך `document.currentScript`.
- בפיתוח מקומי (http) הדפדפן חוסם טעינה של סקריפט http מעמוד https. לכן שם הקוד המלא מוטמע בסימנייה עצמה.

### קיצור iOS (התקנה בלחיצה אחת, אופציונלי)

עושים את זה פעם אחת, באייפון של המפתח. אחר כך כל משתמש מתקין בלחיצה אחת:

1. אפליקציית **קיצורים** ← ➕ ← קיצור חדש בשם `אוטו-פיילוט`.
2. בהגדרות הקיצור (ⓘ) מסמנים **"הצג בגיליון השיתוף"**, וב"סוגי קלט" מגדירים רק **דפי אינטרנט ב-Safari**.
3. מוסיפים את הפעולה **"הרצת JavaScript בדף אינטרנט"**, ומדביקים בה את הפלט של `shortcutScript(<כתובת האפליקציה>)` מתוך `src/bookmarklet/loader.ts`.
4. משתפים את הקיצור ← **"העתקת קישור iCloud"**, ושמים את הקישור ב-`IOS_SHORTCUT_URL` שב-`src/app/config.ts`.

אחרי זה, באייפון האפליקציה מציגה כפתור **"התקנת הקיצור"**. השימוש: מתחברים ל-Inbar ← כפתור השיתוף ← אוטו-פיילוט.

> הקיצור עדיין לא נבדק על מכשיר אמיתי. צריך לבדוק אותו פעם אחת לפני שמפרסמים את הקישור.

### משוב, סקר ותרומות

הערכים נמצאים ב-`src/app/config.ts`:

- **סקר איפיון צרכים (Google Forms):** פותחים את [script.google.com](https://script.google.com) ← פרויקט חדש ← מדביקים את `scripts/create-feedback-form.gs` ← ▶ הפעלה. מעתיקים את ה-Responder link מהיומן (Execution log) אל `FEEDBACK_FORM_URL`. עד שהערך מוגדר, כפתור המשוב פותח מייל מוכן.
- **קנו לי קפה:** נרשמים ל-[Buy Me a Coffee](https://buymeacoffee.com) ושמים את הקישור ב-`DONATE_URL`. כל עוד הערך ריק, הכפתור מוסתר.

### מגבלות ידועות

- הפסקות של חלק מיום, כמו יריד קריירה או טקסי זיכרון, מופיעות בלוח השנה האקדמי רק כטקסט חופשי, ולכן לא נלקחות בחשבון.
- אם Inbar ישנה את מבנה הטבלה, `parseSchedule` יזרוק שגיאה ברורה. העמודות מזוהות לפי כותרת, לא לפי מיקום.
- שעות השיעורים מחושבות לפי השעון של המכשיר, ומניחות שהוא באזור הזמן של ישראל.
